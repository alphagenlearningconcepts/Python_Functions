Core Concept

Why Use Functions?

PROBLEM: REPETITIVE CODE

Without functions, you must copy-paste lines every time you need them:

# Greet Player 1
print("Welcome to the game!")
print("Score reset to 0")

# Greet Player 2
print("Welcome to the game!")
print("Score reset to 0")

# Greet Player 3
print("Welcome to the game!")
print("Score reset to 0")
Repeated and lengthy code
SOLUTION: FUNCTION MODULE

Define the code block ONCE, then call its name whenever needed:

def greet_player():
  print("Welcome to the game!")
  print("Score reset to 0")

# Call the function 3 times!
greet_player()
greet_player()
greet_player()
Modular and cleaner code!
Modular programming means grouping code into independent function blocks that perform a specific job!

Core Concept

Return Function

Instead of just printing inside, return sends a calculated value back to the main program!

Test Custom Input Name:

When a function uses return, sends the result back to the variable!

return finishes the function execution immediately!
RETURN FUNCTION CODE LIVE OUTPUT
def create_greeting(name):
  return "Welcome back, " + name

# Store returned value in a variable
user_msg = create_greeting("Alice")
print(user_msg)
TERMINAL OUTPUT:
Welcome back, Alice
The returned value is stored inside user_msg, which can then be used anywhere in your program!
Alternative Invocations

Returning Function Calls

Select Invocation Style:

Method A is better if you need to use the variable again.
PYTHON CODE METHOD A: VARIABLE STORE
def sum_three(a, b, c):
  return a + b + c

# Method A: Capture return value in variable
total = sum_three(10, 20, 30)
print("Sum:", total)
TERMINAL OUTPUT:
Sum: 60
Function calls that return data can be placed anywhere a value is expected in Python!
Crucial Distinction

Default vs Return Function

PRINT ONLY FUNCTION
def add_print(a, b):
  print(a + b)

result = add_print(5, 5)
print("Result:", result)
Click Run to observe None!
RETURN FUNCTION
def add_return(a, b):
  return a + b

result = add_return(5, 5)

Click Run to observe stored return value!
the value returned in the return function can be used anywhere in the program
